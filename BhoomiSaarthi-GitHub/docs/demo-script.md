# Demo Script (2–3 minutes)

1. **Problem (20 sec):** Rural families may struggle to understand land documents and mutation steps.
2. **Access model (20 sec):** A trained operator at a Village Land Assistance Centre assists the resident.
3. **Upload (30 sec):** Use fictional/synthetic sample documents.
4. **AI analysis (45 sec):** Show extracted fields and a possible mismatch with uncertainty labels.
5. **Guidance (30 sec):** Show a checklist grounded in official sources.
6. **Human review (20 sec):** Operator explains the report and tracks the case.
7. **Impact & limits (15 sec):** Local digital-service jobs; AI supports—not replaces—official/legal decisions.
